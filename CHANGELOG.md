## [0.3.0] — 2026-07-12

### Changed
- **Полная эфемерность: SQLite удалён.** История чата живёт в памяти комнаты
  (последние `CHAT_HISTORY_CAP`, по умолчанию 50) и умирает вместе с ней —
  после завершения сессии не остаётся никаких данных: ни чатов, ни сессий;
  IP и порты клиентов не логируются и не хранятся. Из деплоя удалён PVC.
- Короткие ссылки комнат: `/r/<id>` вместо `/room/<id>`.
- Мобильная вёрстка комнаты: нижняя панель с крупными touch-таргетами и
  safe-area, сетка тайлов 2 колонки, лента тайлов при активном экране,
  фронтальная камера по умолчанию, кнопка «Экран» скрывается на устройствах
  без поддержки захвата (мобильные браузеры не дают getDisplayMedia).

### Added
- Попап «Поделиться»: QR-код комнаты (серверный SVG `GET /qr.svg?room=<id>`,
  чистый Rust-крейт qrcode) + ссылка с копированием.

## [0.2.0] — 2026-07-12

### Changed
- **Модель комнаты: симметричная встреча вместо «вещающий + зрители»** (протокол
  v2, breaking). Все участники равны и соединены full mesh (WebRTC каждый с
  каждым, до 6 человек); роли broadcaster/viewer удалены, страницы объединены
  в одну комнату с сеткой тайлов.
- Комната создаётся мгновенно кнопкой на главной (`POST /api/rooms`) с
  переходом по ссылке — без диалога захвата экрана; пустая комната живёт
  `EMPTY_ROOM_TTL_SECONDS` (по умолчанию 120с).
- Прекращение показа экрана больше не завершает сессию: комната живёт, пока
  в ней есть хотя бы один участник.

### Added
- Видео и голос у каждого участника: независимые кнопки микрофона и камеры
  с мгновенным mute/unmute (`track.enabled`, без ренегациации); заглушки
  тайлов при выключенной камере, speaking-рамки.
- Показ экрана любым участником, не более одного за раз: серверный «замок»
  (`share-start`/`share-started`/`share-rejected`/`share-stopped`), автосброс
  при дисконнекте владельца.
- Сериализованный писатель истории чата — устранена гонка, при которой
  входящий мог не увидеть только что отправленное сообщение в истории.

## [0.1.0] — 2026-07-12

### Added
- Шеринг экрана «один вещает — до 5 зрителей»: mesh P2P WebRTC звездой вокруг
  вещающего, сигналинг-релей на Rust/axum поверх WebSocket, медиа через сервер
  не проходит. Ванильный фронтенд без сборщиков, тёмная тема.
- Текстовый чат комнаты с историей в SQLite (последние 50 сообщений новому
  зрителю), именами участников и rate-limit'ом.
- Микрофон зрителя (perfect negotiation, ренегациация) и аудио-хаб: вещающий
  ретранслирует микрофоны зрителей остальным; честная индикация «кто говорит»
  (RMS-анализ, устойчивый к жизненному циклу AudioContext).
- Серверный ping/pong-хартбит против тихих обрывов сети.
- Два уровня тестов: протокол сигналинга (43 проверки, чистый Node) и
  браузерные e2e (Playwright + системный Chrome, basic 13 + resilience 16),
  включая режим полностью реальных медиа (E2E_TRY_REAL_CAPTURE/MIC).
- Деплой в KubeSolo (chat.fedorov.it через Cloudflare Tunnel): автодеплой из
  GitHub Actions по пушу в main, гейт тестами, иммутабельные теги prod-<sha>,
  /healthz и /version.json.
